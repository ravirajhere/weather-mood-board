# 🌈 Weather Mood Board

A weather app that changes its entire UI based on current weather.

**Live:** https://ravirajhere-weather.vercel.app

## Features
- 📍 Auto-location detection
- 🎨 Dynamic themes (6 weather moods)
- ✨ Pure CSS animations (rain, sun float, snow)
- 📱 Mobile-first responsive
- 🚫 No API key needed (Open-Meteo)

## Tech
HTML · CSS · Vanilla JS · Open-Meteo API


## Run locally
Just open `index.html` in browser. No build step.

## Why I built this
Normal weather apps show numbers. I wanted to show *feelings*.
Each weather triggers a different visual mood.
